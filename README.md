# 2026-017-Unity学习

> Unity 入门学习工程，用于编辑器界面认识与基础场景搭建练习，包含教学场景、预制体、脚本及界面截图

## 项目内容

1. **Unity 教学工程**

- 工程目录：b-Unity-Teach1，编辑器版本 Unity 2022.3.62f3c1；
- 场景：SampleScene.unity、场景2.unity；
- 预制体：Tank.prefab、金字塔.prefab；
- 脚本：NewBehaviourScript.cs、Test.cs；
- 其他资源：cyx新建文件夹。
